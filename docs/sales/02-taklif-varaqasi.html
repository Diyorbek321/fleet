Деньги теряются в трёх местах — и все три не видны

Проблема
Топливо
Чек есть, сумма есть — но литры, реально попавшие в бак, никто не меряет.
Решение
Фактический расход каждой машины сравнивается с нормой по автопарку. Превышение нормы и подозрительные чеки отмечаются автоматически.
Проблема
Наличные и рейсы
Расчёт с водителем остаётся на бумаге. Какой рейс принёс прибыль — неизвестно.
Решение
По каждому рейсу: выручка − топливо − расходы = прибыль и маржа. По каждой валюте выводится баланс «выдано — потрачено».
Проблема
Время на контроль
Владелец не садится за компьютер искать отчёты — поэтому такие системы умирают через месяц.
Решение
Система говорит сама: сводка, предупреждения и месячный отчёт приходят прямо к вам в Telegram.

Что вы получаете

Для офиса — веб-панель
  • Живая карта и история маршрутов
  • Анализ потерь: перерасход, стоянки вне точек, простой
  • Рейсы и прибыль по каждому рейсу
  • Геозоны, техобслуживание, сроки документов
  • Excel-отчёты для бухгалтера
Для водителя — приложение
  • Смена и геолокация (работает и без трекера)
  • Этапы рейса подтверждаются по GPS
  • Учёт топлива и расходов
  • Фотографирует чек — сумма считывается сама
  • Статус очереди на границе
Для владельца — Telegram
  • Утром: 5 строк по вчерашнему дню
  • Рейс опаздывает — сообщение сразу
  • Не сошлась касса — сообщение
  • Сроки документов: 30 дней / 7 дней / истёк
  • Пишете вопрос — получаете ответ
Система находит сама — никто ничего не ищет:
1. Машина с расходом на 30% выше нормы по парку
2. Заправка, не помещающаяся в один бак
3. Чек на топливо дороже обычного
4. Невозможный расход между двумя заправками
5. Долгая стоянка вне известных зон
6. Истекающие удостоверения и сроки ТО
