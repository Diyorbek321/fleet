# Продающие документы

HTML-исходники лежат здесь, готовые PDF — в корне репозитория. Все тексты на русском языке.

| Файл | Кому | PDF |
|---|---|---|
| `01-sotuv-qollanmasi.html` | **Внутренний** — для продавца. Клиенту не давать. | `FleetWatch-Sotuv-Qollanmasi.pdf` |
| `02-taklif-varaqasi.html` | Одностраничное предложение, остаётся у клиента | `FleetWatch-Taklif-Varaqasi.pdf` |
| `03-pilot-kelishuvi.html` | Пилотное соглашение + лист результатов, заполняется на встрече | `FleetWatch-Pilot-Kelishuvi.pdf` |

Имена файлов остались прежними намеренно: на них ссылаются `build.sh` и внешние ссылки.

## Как изменить

```bash
# 1. Отредактируйте HTML
# 2. Пересоберите:
./docs/sales/build.sh
```

Нужен `weasyprint`: `pip install weasyprint`

## Что обязательно заполнить перед печатью

**`02-taklif-varaqasi.html`:**
- `__________` — цены трёх пакетов
- `[Имя Фамилия]`, `[+998 __ ___ __ __]`, `[@username]`, `[сайт]`, `[email]` — контактные данные

**`01-sotuv-qollanmasi.html`:**
- таблица цен в разделе 13 (`___`)
- демо-цифры в разделе 10 (норма 32,1 л/100км, две машины с ~48 л/100км, 30 стоянок
  вне точек, 3 подозрительные заправки) взяты из данных демо-тенанта — после
  повторного сидирования через `backend/seed_demo_uz.py --reset` цифры изменятся,
  и скрипт нужно будет обновить.
